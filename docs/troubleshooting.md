# 故障排查

## 提示需要登录

先切换到提示失效的账号，再点击“自动发布登录”，在该账号独立 Chrome 窗口重新登录。不要复制 Cookie。

## 出现验证码或访问受限

程序会停止。请在对应账号的独立 Chrome 窗口人工完成验证，然后重新执行。程序不会绕过验证。

## 页面结构未识别

诊断文件位于用户所选数据目录的 `diagnostics\<account_id>`。文件已做基础脱敏，不要直接公开发送未检查的诊断文件。

## API 鉴权失败

检查 Base URL、模型名称和 API Key。服务商的模型名和接口地址以其官方控制台为准。

## 文章未发布但已生成

Markdown 会保留在当前账号的文章目录中。修复登录或分类后，点击“重新发布最近文章”即可直接重发原文，不会再次生成。

## 定时任务没有执行

运行 `python -m blogpost schedule status` 检查状态，并确认账号已启用。计划任务包含所有启用账号的发布时间，并启用了 StartWhenAvailable。
