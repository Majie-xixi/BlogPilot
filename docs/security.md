# 安全说明

- 不保存 51CTO 明文密码；每个账号只在本机保存独立自动化浏览器 Profile 登录会话。
- API Key 经 Windows DPAPI 加密，不写入源码、配置 JSON、SQLite 或普通日志。
- 日志自动隐藏 Authorization、Cookie、Token、Password 和 API Key。
- 不绕过验证码、安全挑战或访问限制。
- 多账号能力只用于管理用户本人合法账号，不进行刷阅读、点赞、评论、账号农场或活动规则规避。
- 最终发布点击只执行一次；结果不明确时状态为 `unknown`，禁止自动再次提交。
- 历史文章目录只读；程序只在用户首次启动时选定的 BlogPilot 数据目录内写入配置、数据库、会话、日志、诊断文件和生成文章。
- 自动化浏览器启动参数禁用组件更新、后台联网、同步、预测加载和本地生成式 AI 功能。
- 账号配置、Cookie、数据库、日志、文章和本地需求均被 Git 忽略；标准安装包只包含程序，不包含任何本机数据。
- 升级和卸载不会删除用户选择的数据目录，避免误删文章与账号会话。
