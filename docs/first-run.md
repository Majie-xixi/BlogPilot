# 首次运行

1. 第一次启动时选择专用数据目录，例如 `E:\BlogPilotData`。如果已有 BlogPilot 数据，请直接选择原目录，不要选择程序安装目录。
2. 进入“全局设置”。
3. DeepSeek 默认使用 OpenAI 格式地址 `https://api.deepseek.com`；其他服务商请填写其官方 OpenAI 兼容地址。
4. API Key 使用 Windows 当前账户的 DPAPI 加密，无法复制到另一台电脑或另一个 Windows 账户解密。
5. 默认开启安全试运行。它会生成文章、保存 Markdown 并填充 51CTO 编辑器，但不会点击最终发布。
6. 打开“账号管理”，设置每个账号的主页、发布时间、分类、博文类型、内容方向与关键词；关键词会直接约束文章主题。
7. 切换到每个账号后点击“自动发布登录”。每个账号使用独立 Chrome Profile，请分别完成登录和验证码。
8. 首次试运行必须人工确认：标题、正文、Markdown 排版、原创标记、文章分类、二级分类和个人分类。
9. 确认无误后才能关闭安全试运行。关闭后的一键操作、批量操作和每日任务会真实发布。
10. 安装计划任务后，在主界面或 `schedule status` 检查状态。统一任务包含所有启用账号的发布时间。

安装升级不会改写已有配置；卸载也不会删除所选数据目录。若要彻底清理数据，需要用户自行确认后手动删除该目录。

如果某个账号当天已经成功发布，该账号的自动任务会跳过，但不会影响其他账号。重发最近文章只使用已保存文件，不会重新生成。
